# copy-rm

拷贝漫画 Android 客户端 **3.0.9** 的整理版安装包。

## 下载

安装包在 **Releases** 页面：

👉 https://github.com/newliver666/copy-rm/releases/latest

文件名：`copymanga-3.0.9.apk`（约 109 MB）

## 安装步骤

1. 手机浏览器打开上面的 Releases 链接
2. 下载 `copymanga-3.0.9.apk`
3. 系统设置里允许「安装未知来源应用」
4. 点击 APK 安装，完成后打开

## 特性

- 已去除应用内广告位
- 支持账号登录
- 漫画详情页、章节阅读页正常
- 支持简体 / 繁体界面

## 注意事项

- **安装前请先卸载官方版**。本包与官方版签名不同，直接覆盖安装会提示签名冲突。
- 卸载官方版会清掉本地数据，登录状态需要重新登录。
- 建议 Android 8.0 及以上；最低 Android 5.0。
- 漫画章节本身可免费阅读；写真等需要「写真币」的付费内容不在本包能力范围内。
